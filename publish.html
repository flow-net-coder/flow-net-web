Publish a project

Upload your code bundle and environment variables.

Use FLOW-NET to deploy a live app from your code archive and a .env file. The published app will be served from the FLOW-NET live apps platform.

Compress your static app or frontend build into a zip file, upload a valid .env file, and FLOW-NET will publish it under a live path.

What to include

Publish successfully with these files.

  • A zip archive containing your static app files.
  • A .env file with the environment variables the app requires.
  • An app name so FLOW-NET can create a unique live path.
